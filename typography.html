01 / Reading & emphasis

Room for the words

A paragraph should be comfortable to read from the first word to the last. A consistent rhythm gives each sentence room, while a considered line length makes the next line easy to find.

This second paragraph shows the space between ideas. Resize the preview to see how the same passage wraps, and increase the text size to check that the layout continues to work.

Use bold for important information, italic for emphasis, and both when the meaning calls for it. A link to the brand defaults stays recognisable through its underline.

The b element draws attention; the i element marks an alternate voice. Their appearance matches bold and italic, while their meaning differs from strong importance and emphasis.

Small text / Supporting notes and captions start at 14px equivalent. Essential information stays at body size.

Accents & symbols: café, naïve, coöperatie, Straße, Ångström, €29.50, £18.00, 0123456789. Chemistry uses H2O; an area might be 24m2.

02 / Lists

Order where it matters

Use an ordered list when the sequence is meaningful.

  1. Start with the reader’s main task.
  2. Arrange the information.
    1. Introduce the subject.
    2. Add the details the reader needs.
  3. Check the result at different text sizes and screen widths.

Use an unordered list when the items are peers.

  • Clear headings and readable paragraphs.
  • Consistent text treatments.
    • Bold for importance.
    • Italic for emphasis.
  • Enough room for a longer list item to wrap naturally, without losing the alignment of its marker or the relationship to the items around it.

06 / In context

Designing a useful reference

i12e / Design notes

A design reference connects a decision to the places it will be used. A heading introduces the subject. The paragraphs explain it, and the details help someone put it into practice.

Start with the reading experience

The words come first. Give the text a clear order, keep related ideas together, and use emphasis with intent. Typography should help the reader understand what matters.

  • Use a descriptive heading.
  • Keep supporting text close to its subject.
  • Make further guidance easy to recognise.

Family, emphasis & rhythm

  • Roboto for headings, prose, and controls; Roboto Mono for brand accents, code, and specimen labels.
  • Regular 400, semibold headings 600, bold 700. Italic and bold italic use real italic font styles.
  • Body line-height 1.6; heading line-height 1.2; paragraph spacing 1em; prose measure 65ch.
  • Captions and control labels start at 0.875rem / 14px equivalent. Tracking uses the typeface’s normal spacing.

Compact interface roles

Document headings use the responsive scale. Cards and controls use explicit compact roles without changing their semantic heading levels. All heading roles use 1.2 line-height; control values, labels, and supporting text use 1.6.

Header navigation

Every page uses the same header pattern: a 16px-equivalent Roboto Mono brand identifier, plain Roboto navigation links following the 16–18px body scale, and a separate Appearance control. All four links stay visible in the same order: Design Index, Logotype, Typography, and Colours. The current page is identified with aria-current. Navigation follows the page width; embedded specimens follow their own available width.

Shared implementation & artwork

assets/css/typography.css defines the families, scale, rhythm, and compact roles. assets/js/typography.js follows viewport width for pages and actual container width for embedded specimens. Preview changes affect only their specimen.

The animated logotype is an intentional exception: Roboto Mono 400 at a 48px default, with its own measured letter spacing and animation geometry. Its size control adjusts the artwork, independently of document typography. The large “Aa” on the design index is a decorative type specimen.

Colour roles

The colour specification defines the approved light and dark palette. This page shares assets/css/colours.css and its semantic properties for text, links, warnings, backgrounds, surfaces, and borders.

Light mode uses #191919 main text, #666666 secondary text, #0E47CB links, #ffffff surfaces, and a #f7f7f7 page. Dark mode uses #f7f7f7 main text, #bdbdbd secondary text, #9fb5ea links, #242424 surfaces, and a #191919 page. Warning text uses the appropriate orange shade.

Approved text roles meet at least 4.5:1 contrast on their intended backgrounds. Links remain underlined and warnings remain labelled. Appearance changes are temporary and start light on reload.

Reading & accessibility checks

The spacing preset applies at least 1.5 line-height, 2em paragraph spacing, 0.12em letter spacing, and 0.16em word spacing, following W3C’s text-spacing guidance. It preserves a higher selected line-height and restores your settings when switched off.

Also check the entire page with browser text enlargement to 200% and at a narrow 320px viewport. Preview text size only changes the specimens; it does not replace browser zoom. New colours should follow W3C’s contrast guidance.
