    01 / Fixed values

    The palette

    A scale is an inventory, not a promise that every pairing is readable. Use the roles below for approved combinations. Select a HEX value or RGB button to copy it.

    Blue signals action

    Use the primary blue for actions and selected states. Light blue surfaces and lighter dark-mode links come from the same range.

    Neutrals support reading

    Use white and grey surfaces, charcoal body text, and readable secondary text. Decorative lines should remain quiet; input boundaries need stronger contrast.

    Status colour has meaning

    Green means success, orange warning, red error, and blue information. Always include a label or symbol. Yellow is reserved for the flag.

    Blue values follow ECL EU v5.2.1; i12e numbers them 50–950 instead of ECL’s 5–180. The neutral and status scales are i12e choices. Status scales mix the shade-600 seed with white or black in encoded sRGB, rounded to the nearest channel value. Print and chart palettes are outside this specification.

    02 / Approved assignments

    Give each colour a job

    Both appearances use the same palette. The roles choose shades for their surroundings. Primary buttons keep the brand blue in both modes; dark links and button outlines use lighter shades.

    05 / Provenance

    Sources & decisions

    Official EU interface and emblem guidance cover different uses. The interface blue is #0E47CB. The emblem retains #003399 and #FFCC00. These documented differences do not imply a website is disregarding the emblem specification.

    • EU Publications Office: links and main buttons — the #0E47CB interface reference.
    • Europa Component Library, EU theme v5.2.1 — the fixed blue scale. ECL primary-100 is i12e blue-600.
    • Interinstitutional Style Guide: the European emblem — the flag’s blue and yellow.
    • W3C: text contrast, non-text contrast, and use of colour — contrast thresholds and meaning beyond colour.
    • Tailwind CSS theme variables and manual dark mode — export format checked against v4.3.3.

    Reference decisions verified 6 September 2026. Start light; theme switches and experiments last only until reload. The shared stylesheet is the source of the displayed values.
